# Material Symbols Outlined

Google Material Symbols, Outlined, 24 px, light weight (300), unfilled.
Source filenames use the `_wght300_24px.svg` suffix.
Downloaded from https://github.com/google/material-design-icons/tree/master/symbols/web
on 2026-11-13. Original SVGs are kept unmodified and embedded in the executable;
the renderer uses their alpha masks to tint them for idle, hover and disabled states.
